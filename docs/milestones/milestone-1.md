# Milestone 1 acceptance map

Milestone 1, the walking skeleton, is done when every item of the Build Brief's checklist (Milestone 1: acceptance
criteria) is ticked and CI is green on `main`. This map names, for every checklist item, the tests that prove it,
or the manual steps where a test cannot (the start-up item). Test names are `Class.Method`; the projects are under
`tests/`. The reference calculations are the 13 steps of the Build Brief's table, reproduced to the last decimal.

Property-based runs and the DCO check arrived with step 11 (Build Brief, step 11; D-36, D-27); everything else was
built in steps 1 to 10 and is unchanged by this map.
