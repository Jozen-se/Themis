# Security policy

## Reporting a vulnerability

Please report a suspected vulnerability privately through GitHub's private vulnerability reporting, which is enabled
on this repository: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public
issue, pull request or discussion for it.

Include what you found, the affected version or commit, and the steps to reproduce it. You will get an answer
through the same private report.

## Scope

In scope is the code in this repository: the Themis kernel, its host, its migrator, the database bootstrap and the
build and CI configuration. Third-party dependencies are out of scope unless the way this repository uses them makes
it vulnerable; report problems in a dependency itself to its maintainers.

## Bounty

There is no bug bounty.
